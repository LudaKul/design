# Техники тест-дизайна

✏️ Исчерпывающее тестирование, как известно, провести невозможно. За исключением тривиальных случаев. Чтобы провести тестирование тщательно и не затратить на это коллосальное количество времени существуют техники тест-дизайна. На курсе я изучила эквивалентное разбиение, попарное тестирование, таблица принятий решения, а также бисекционное деление, декомпозиция, диаграмма переходов и состояний, предугадывание ошибок. Несколько из них применила на практике во время тестирования [сайта](https://qa.demoshopping.ru/)
